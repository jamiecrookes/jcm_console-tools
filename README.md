# Jcm_Console-Tools

## Introduction
Jcm_Console-Tools is a fun and useful module that gives a little added flair
to your scripts, from outputting nerd font glyphs and status messages that look
like Linux boot messages to a handy, arrow-key driven console menu for presenting
a list of options and a handy way to choose between them.

## Installation Script
You'll find a handy installation script in the `code` folder. This can be run to
perform an installation into you `$HOME\Documents\PowerShell` folder. If you need
to install this module in Windows PowerShell rather than PowerShell Core, or a
module folder of your choice you'll need to edit the installation script to reflect
your folder choice before you run it to perform the install.
